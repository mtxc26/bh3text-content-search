《崩坏3》文本搜索 API

搜索《崩坏3》主线第一部、第二部及往世乐土的对话文本。

HTML 搜索

GET /search?q={关键词}

返回渲染好的 HTML 页面，包含匹配的关键词、上下文及指向对话页面的链接。

参数：

  • q - 搜索关键词（必填）
  • offset - 结果偏移量（默认 0）
  • limit - 每页结果数（默认 20，最大 50）

JSON API

GET /search?q={关键词}&format=json

返回 JSON 格式的搜索结果。

示例

GET /search?q=琪亚娜
GET /search?q=芽衣&format=json
GET /search?q=往世乐土&offset=20&limit=10

搜索范围

  • 主线第一部（第 1-42 章）
  • 主线第二部（第 1-12 章）
  • 往世乐土
