《崩坏3》文本搜索 API

搜索《崩坏3》主线第一部、第二部及往世乐土的对话文本。

搜索语法

  • 空格分隔：多个关键词用空格分隔，匹配同时包含所有关键词的行。
    琪亚娜 芽衣 → 同时包含「琪亚娜」和「芽衣」的对话
  • 引号精确匹配：用双引号包裹，匹配完整短语（含空格）。
    "出击" → 精确匹配「出击」
    "琪亚娜 出击" → 精确匹配含空格的完整短语
  • 正则表达式模式：设置 regex=1 后，q 会直接按 new RegExp(q, flags) 解释，不再进行空格拆分。flags 参数可填写 gi、m 等标志。
    q=琪亚娜.*芽衣&regex=1 → 使用正则匹配同时包含两者的行

HTML 搜索

GET /search?q={关键词}

参数：

  • q - 搜索关键词；在普通模式下支持空格多关键词 + 引号短语，在正则模式下直接作为正则表达式主体
  • a - 按角色筛选（可选，仍然是普通文本筛选，可与正则正文搜索同时使用）
  • regex - 是否启用正则表达式搜索（可选，复选框参数）
  • flags - 正则标志（可选，例如 gi）
  • offset - 结果偏移量（默认 0）
  • limit - 每页结果数（默认 100，最大 1000）

JSON API

GET /search?q={关键词}&format=json

JSON API 接受与 HTML 搜索相同的参数：a、regex、flags、offset、limit。

示例

GET /search?q=琪亚娜
GET /search?q=琪亚娜 芽衣
GET /search?q="琪亚娜 出击"
GET /search?q=布洛妮娅&a=希儿
GET /search?q=芽衣&format=json
GET /search?q=琪亚娜.*芽衣&regex=1
GET /search?q=芽衣&regex=1&flags=i
